Database Systems Laboratory Works
(BSU FPMI Course)

This repository contains a collection of laboratory works completed during the "Database Management Systems" course at the Faculty of Applied Mathematics and Computer Science, BSU.

Topics covered:

Database schema design and normalization (1NF, 2NF, 3NF)

DDL operations: CREATE, ALTER, DROP (tables, constraints, indexes)

DML operations: INSERT, UPDATE, DELETE, SELECT with complex conditions

Multi-table queries: INNER JOIN, LEFT/RIGHT JOIN, FULL OUTER JOIN

Aggregate functions: COUNT, SUM, AVG, GROUP BY, HAVING

Practical work with MySQL
